## How to Host Live on GitHub Pages
1. Create a new public repository on GitHub (for example, `ap-property-development`).
2. Upload the `index.html` file from this folder to the root of your repository and commit changes.
3. Go to **Settings -> Pages** in your GitHub repository.
4. Under **Build and deployment -> Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
5. Within 1–2 minutes, your website will be live at `https://<your-username>.github.io/ap-property-development/`!
